=== دليل تجميع وتشغيل التطبيق واستخراج ملف الـ APK ===

[ الطريقة الأولى: استخراج ملف الـ APK عبر Android Studio في دقيقة واحدة ]
1. افتح برنامج Android Studio.
2. اختر من القائمة: File -> Open (أو Open an Existing Project).
3. اختر هذا المجلد المستخرج (AndroidVoiceApp).
4. من القائمة العلوية اضغط على:
   Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)
5. انتظر حوالي دقيقة حتى يظهر إشعار بالأسفل:
   "APK(s) generated successfully"
6. اضغط على كلمة "locate" باللون الأزرق.
7. مبروك! سيفتح لك المجلد الذي يحتوي على ملف:
   app-debug.apk
8. انسخ هذا الملف إلى هاتفك عبر واتساب أو تليجرام أو كابل وثبته فوراً!

[ الطريقة الثانية: التجميع التلقائي السحابي مجاناً عبر GitHub بدون تثبيت أي برامج ]
1. ارفع هذا المجلد إلى حسابك في موقع GitHub.com.
2. افتح تبويب "Actions" في مستودع GitHub.
3. ستجد أن خوادم GitHub قامت بتجميع ملف الـ APK تلقائياً.
4. اضغط على النتيجة وحمّل ملف VoiceAssistant-App-Debug.apk مباشرة على هاتفك!
